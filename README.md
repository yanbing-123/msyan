# 🚄 TrainTicket - 简易火车票购票系统

功能完整的火车票购票系统 MVP 版本，支持车次查询、选座购票、订单管理。

## ✨ 功能特性

### 车次查询
- 🚄 出发站→到达站 + 日期查询
- 📋 车次列表展示
- ⏰ 始末时间 + 历时
- 💰 价格信息（二等/一等/商务座）
- 📊 余票显示

### 选座模块
- 🪑 **可视化座位图**（8 行 5 列）
- 🎯 座位类型（二等座/一等座/商务座）
- 🎨 座位状态（可用/已选/已售）
- 🎯 最多选 4 座
- 💼 布局说明（A/F 靠窗）

### 订单模块
- 📝 乘客选择（支持添加乘客）
- 💰 实时价格计算
- 🔢 8 位取票码
- 🎫 电子票展示

### 数据持久化
- 💾 LocalStorage 存储
- 🔄 刷新数据不丢失

## 📖 使用流程

### 1. 查询车次
- 选择出发站/到达站
- 选择出发日期
- 点击"查询"按钮
- 查看车次列表

### 2. 选择车次
- 点击车次卡片
- 查看详细信息
- 了解余票情况

### 3. 选择座位
- 查看座位图
- 点击绿色座位（可用）
- 灰色座位（已售）不可选
- 最多选择 4 个座位

### 4. 添加乘客
- 点击"添加乘客"
- 输入姓名和身份证号
- 在乘客列表中选择

### 5. 确认订单
- 查看订单摘要
- 点击"立即支付"

### 6. 获取电子票
- 支付成功后显示电子票
- 8 位取票码
- 可在订单页面查看

## 💡 核心功能代码

### 座位选择逻辑

```javascript
function toggleSeat(seatId, price, type) {
    const index = selectedSeats.indexOf(seatId);
    if (index > -1) {
        // 取消选择
        selectedSeats.splice(index, 1);
    } else {
        // 添加选择（最多 4 个）
        if (selectedSeats.length >= 4) {
            showToast('最多可选 4 个座位', 'warning');
            return;
        }
        selectedSeats.push(seatId);
    }
    
    updateOrderInfo();
}
```

### 订单生成流程

```javascript
function payOrder() {
    // 1. 验证选择
```
